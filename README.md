# AÏA — Prototype clinique

Application HTML de démonstration pour le suivi clinique des violences faites aux femmes et du psychotrauma.

**Statut** : prototype produit. Validation clinique en cours.

## Contenu

App single-page autonome (HTML + vanilla JS, persistance localStorage), comportant :

- **Côté praticien** : dossier patiente, 9 échelles validées (WAST, Danger Assessment Campbell, PCL-5, PHQ-9, GAD-7, PTCI-9, IES-R, ITQ, DES-T), CMI guidé HAS 2011, plan de sécurité, module EMDR (protocole 8 phases, plan de ciblage, séances avec SUD/VOC), module TCC (Impact Statement, stuck points CPT Resick, tableau de Beck, hiérarchie dexposition Foa).
- **Côté patiente** : journal, ancrage 5-4-3-2-1, cohérence cardiaque, plan de sécurité personnel, carnet de pensées (Beck simplifié), contenus pédagogiques EMDR/TCC, accès rapide aux numéros durgence (3919, 17, 114, 3114, 119, 3018).

## Avertissements

- **Échelles** : versions paraphrasées pour démo. Production = versions officielles validées (BEH 2021, Campbell 2009, DSM-5, Cloitre 2018, Weiss & Marmar 1997, Foa 1999, Carlson & Putnam 1993).
- **Données** : la patiente "Anaïs M." est entièrement fictive.
- **Pas un dispositif médical**. Pas un substitut au soin. En cas durgence : 3919, 17, 3114.

## Sources cliniques

HAS (2007, 2025), INSERM (2015), OMS (2013), MIPROF/ONVF, Cn2r, EMDR France, IFEMDR, ISTSS, Trauma Aid France, Resick (CPT), Foa (PE), Shapiro (EMDR), Iracane-Coste & Tarquinio.
